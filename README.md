# DS_Day01_26 - Manufacturing Analysis

## Project Title
Manufacturing Production and Machine Efficiency Analysis

## Objective

The objective of this project is to analyse machine production,
defective units, downtime, and good units to understand machine
performance and identify areas for improvement.

## Dataset

The dataset contains:

- Machine ID
- Units Produced
- Units Defective
- Downtime Minutes
- Good Units

## Machines Analysed

- M-101
- M-102
- M-103
- M-104
- M-105

## Analysis Performed

- Data cleaning and validation
- Exploratory Data Analysis
- Defect rate analysis
- Machine efficiency analysis
- Downtime analysis
- Good unit comparison
- Machine performance comparison
- Data visualisation

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- Jupyter Notebook

## Conclusion

The analysis compares production output, defective units,
downtime, and good units across different machines to identify
machine performance patterns and potential areas for operational
improvement.
